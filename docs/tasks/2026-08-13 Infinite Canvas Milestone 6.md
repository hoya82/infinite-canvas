# Infinite Canvas — Milestone 6 (컬러 피커)

작성일: 2026-08-13
상태: 구현 완료(자동 검증 완료), 브라우저 수동 검증은 이후 체크포인트에서 진행

## 개요

Krita 스타일 컬러 피커(HSB + RGB)를 붙이고, 지금까지 만들 기회가 없었던 최소한의 툴바도 이 마일스톤에서 함께 만들었다 — 색상 스워치를 둘 자리도 필요했고, 애초에 브러시 크기를 UI에서 바꿀 방법이 아직 없었기 때문이다(원래 8개 마일스톤 계획에는 툴바가 별도 항목으로 없었지만, M6이 실질적으로 그 UI가 필요해지는 지점이라 여기서 함께 처리했다).

## 구현 내용

- `color.ts` — HSB↔RGB↔hex 순수 변환 함수. 표준 HSV→RGB 공식을 6분할(sextant) 룩업 테이블로 구현했다(원래 if/else 체인이 "항상 즉시 덮어써지는 초기값" 때문에 `no-useless-assignment` lint 규칙에 걸려서 정리했다).
- `ColorPicker.svelte` — HSB 탭(Hue 슬라이더 + Saturation×Value 사각형, 클래식 CSS 그라디언트 두 겹 + `hsl(var(--hue))` 트릭으로 렌더링)과 RGB 탭(R/G/B 슬라이더), 그리고 항상 보이는 hex 입력 필드. 내부 상태는 HSB를 단일 진실 공급원으로 두고 RGB/hex는 `$derived`로 계산하며, hex 입력창은 Svelte 5.25+의 **쓰기 가능한 `$derived`**(로컬에서 덮어쓸 수 있는 파생값)로 구현해 별도의 `$state`+동기화용 `$effect` 쌍을 두지 않아도 되게 했다. 선택한 색은 `$effect`로 `toolState.color`에 반영한다(컴포넌트 로컬 상태를 외부 싱글톤 스토어로 내보내는 용도라 — 로컬 상태끼리의 동기화를 피하라는 일반적인 `$effect` 권장 사항과는 다른 경우다).
- `Toolbar.svelte` — 펜/지우개 전환 버튼, 도구별 크기 슬라이더(`toolState.activeSize`), 전경색 스워치(클릭 시 `ColorPicker` 팝오버 토글).
- `+page.svelte`를 상단 툴바 + (캔버스+레이어패널) 워크스페이스의 세로 레이아웃으로 재구성했다.
- 아이콘은 기존 정책대로 `lucide-svelte/icons/pencil`, `lucide-svelte/icons/eraser` 딥 임포트.

## 알려진 한계 (의도적으로 남겨둠)

컬러 피커 팝오버는 바깥을 클릭해도 안 닫힌다(스워치를 다시 눌러야 닫힘) — 클릭-바깥-감지는 이 마일스톤의 핵심이 아니라고 판단해 넣지 않았다. 필요하면 후속 작업으로 추가할 수 있다.

## 검증

- `color.spec.ts`(순수 로직): 알려진 색상(빨강/초록/파랑/흰색/검정) 변환, 0°/360° 동치, RGB↔HSB 왕복 변환, 무채색의 saturation=0, hex 3자리/6자리·대소문자 파싱, 잘못된 형식에 대한 null, hex 왕복 보존 — 8개 전부 통과.
- 전체 스위트 42개(M1~M6 누적) 통과, `svelte-check` 0 에러, lint 통과, 빌드 성공.
- 브라우저 수동 검증(SV 사각형 드래그, Hue 슬라이더, 실제로 그려지는 색)은 이후 체크포인트에서 진행한다.
